# Инвентаризация статей и связанных SEO-страниц

Снимок актуализирован по структуре сайта на 13 августа 2026 года. В него включены опубликованная статья о кожаном блокноте А5 на кольцах и новая статья о подготовке ТЗ на ручки для сумок.

## Как считались данные

- Объём — примерное число слов в основном тексте `<article class="article-body">`; служебная информация об авторе и датах, меню, подвал и кнопки CTA не учитывались.
- Исходящие внутренние ссылки перечислены для содержательной части статьи и её нижнего CTA; одинаковые ссылки не повторяются. Общие ссылки шапки и подвала не перечисляются у каждой статьи.
- «SEO-страница» — коммерческая страница товарной группы внутри `/catalog/`. «Товарная страница» — страница конкретной позиции каталога.
- Проверка Schema.org включала разбор всех блоков JSON-LD. Ошибок JSON в статьях не найдено.
