# Проверка поиска перед публикацией

Из корня актуальной рабочей копии:

```powershell
python tools/check_search.py
python tools/test_check_search.py -v
```

Проверка работает без сети и сторонних библиотек. Она сверяет все страницы
из `sitemap.xml` и отдельно каждую карточку в `catalog/index.html`
с `assets/search-index.json`. Поэтому новый товар будет обнаружен даже до
добавления в карту сайта. Проверяются тип записи, артикул, возможность найти
товар по словам полного названия из каталога, повторные записи, существование
страниц и якорей. Код завершения 1 означает ошибку, 0 - успешную проверку.

`tools/check_public.py` запускает эту же проверку для готового пакета
`dist-regru`. Существующий workflow `.github/workflows/deploy-regru.yml`
вызывает `check_public.py` перед доставкой: при пропуске публикация останавливается.
Обходить этот этап при ручной публикации нельзя.

При добавлении товара обновляйте карточку, каталог и поисковый список вместе.
В поисковой записи товара указывайте `type: product`, точный `sku`, постоянный
URL, название из каталога и полезные синонимы в `keywords`.
Проверка полноты не гарантирует нахождение по любому синониму или опечатке.
