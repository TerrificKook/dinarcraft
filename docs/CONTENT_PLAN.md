План актуализирован по текущей структуре сайта на 13 августа 2026 года. Он не утверждает новые темы, сроки или приоритеты: найденные возможности сначала нужно проверить по бизнес-задаче и поисковому интенту.

## Значение статусов

| Статус | Что означает |
|---|---|
| опубликовано | Материал существует, технически подключён и имеет достаточную глубину |
| готово к публикации | Материал создан и технически подключён локально; commit и публикация ещё не выполнялись |
| требует расширения | Страница работает, но основной текст слишком короткий для заявленной темы |
| требует технической проверки | До изменения текста нужно проверить конкуренцию URL, внутренние связи или роль страницы |
| запланировано | Тема подтверждена владельцем сайта, но ещё не опубликована |
| возможная новая тема | Найден пробел в покрытии каталога; решение о создании статьи не принято |

## Подтверждённые запланированные темы

Статус **«запланировано»** пока не назначен ни одной теме. В HTML нет карточек «Материал в подготовке», а других подтверждённых планов репозиторий не содержит. Добавлять будущую карточку или URL в sitemap до появления рабочей страницы не следует.

## Предлагаемая последовательность без назначения новых тем

1. Сначала развести оставшиеся пересекающиеся URL по цене, ремням и ежедневникам; роли страниц о капхолдерах и мерче уже зафиксированы.
2. Затем расширить три короткие опубликованные статьи, сохранив их URL.
3. После этого исправить внутренние связи существующих статей, SEO-страниц и товаров.
4. Только затем оценивать возможные новые темы по ассортименту и реальному спросу.
5. Статус «запланировано» присваивать только после отдельного подтверждения владельцем сайта.
