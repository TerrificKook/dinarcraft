# README

Это пакет контекста для отдельного ChatGPT Project по сайту `dinarcraft.ru`.

Цель пакета - быстро объяснить новому чату, что уже есть на сайте, как он устроен, какие товары и SEO-страницы существуют, какие правила нельзя нарушать.

## Какие файлы загрузить в ChatGPT Project

Рекомендуется загрузить все Markdown-файлы из этой папки:

- `PROJECT_BRIEF.md`
- `SITE_STRUCTURE.md`
- `PRODUCTS.md`
- `SEO_STATUS.md`
- `DESIGN_STATUS.md`
- `NEXT_STEPS.md`
- `CODEX_RULES.md`
- `README.md`

## Какие файлы не надо загружать

Не нужно загружать:

- изображения;
- видео;
- Excel;
- CSV;
- рабочие импортные папки;
- исходные фото;
- весь проект сайта целиком;
- большие HTML/CSS/JS-файлы без отдельной необходимости.

Для старта ChatGPT Project достаточно документов из `_project_context`.

## Как использовать эти документы

1. Загрузить Markdown-файлы в отдельный ChatGPT Project.
2. В инструкции проекта добавить, что это контекст сайта DINAR handmade / `dinarcraft.ru`.
3. Использовать `CODEX_RULES.md` как правила поведения для задач по сайту.
4. Использовать `PROJECT_BRIEF.md` для общего понимания бизнеса.
5. Использовать `SITE_STRUCTURE.md` и `PRODUCTS.md` перед задачами по страницам и каталогу.
6. Использовать `SEO_STATUS.md` перед SEO-задачами.
7. Использовать `DESIGN_STATUS.md` перед дизайн-задачами.
8. Использовать `NEXT_STEPS.md` как список ближайших задач.

Важно: этот пакет не заменяет сам проект. Если нужно менять сайт, Codex должен работать с локальными файлами проекта и сначала проверять актуальное состояние.
