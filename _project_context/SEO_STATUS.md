## Title и description

У основных HTML-страниц есть:

- `<title>`;
- `<meta name="description">`.

Файлы подтверждения Яндекса не являются обычными страницами сайта, поэтому у них нет title/description, и это нормально.

## Open Graph

Open Graph найден на основных страницах сайта:

- `og:title`;
- `og:description`;
- `og:type`;
- `og:url`;
- `og:image`;
- `og:locale`.

Для товарных страниц используется `og:type="product"`, для статей - `og:type="article"`, для обычных страниц - `og:type="website"`.
